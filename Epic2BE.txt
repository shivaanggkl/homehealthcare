Epic 2 Backend Backlog
HomeHealthCare

Purpose

This document converts Epic 2 from `Requirements.txt` into a backend delivery backlog.

Epic 2 title

Agency setup and configuration

Epic 2 feature scope from the requirements

- agency profile
- service lines
- visit types
- caregiver skills/certifications
- task templates
- documentation templates
- branch policies
- alert rules
- mileage/pay settings

Planning assumptions

- Epic 1 is complete and available as the security, tenancy, RBAC, audit, and session foundation
- all Epic 2 data remains agency-scoped unless explicitly branch-scoped
- branch overrides are supported only where the business model clearly needs them
- all configuration changes are audit-sensitive
- all admin-facing Epic 2 features need public HTTP APIs for the frontend

Scope rule

- Include only Epic 2 backend work
- Cover domain model, public APIs, validation, RBAC, audit, and tests
- Do not include frontend-only tasks

Status legend

- NOT STARTED: no Epic 2 implementation exists yet
