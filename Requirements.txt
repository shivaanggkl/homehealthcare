3C. Core product workflows
Workflow 1: Intake to first visit

Referral or new client arrives → patient/client profile created → care needs entered → payer/service type selected → care team eligibility checked → first visit scheduled → caregiver notified.

Workflow 2: Daily scheduling and fulfillment

Scheduler views open demand → system suggests best caregiver → conflict and travel checks → visit assigned → caregiver confirms → reminders sent.

Workflow 3: Field execution

Caregiver opens mobile app → sees route and visit details → checks in with GPS/time proof → follows care task checklist → records notes/photos/signature → checks out → exceptions flagged instantly.

Workflow 4: Exception handling

Missed visit / late check-in / signature missing / task incomplete / incident / infection / escalation → routed to coordinator or QA with SLA.

Workflow 5: Review and revenue readiness

Visit completed → QA checks completeness → required signatures/orders/docs validated → ready for invoicing/claim workflow.
